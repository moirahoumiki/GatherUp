三套并行候选

不在「v6 暖纸风」上迭代，而是重建。三套方案在结构、色彩、圆角、阴影、字号阶梯上刻意拉开距离—— 不是换主色，而是换气质。每套都含完整 token（亮/暗成对）、收敛到 3 个变体的卡片体系、 loading / empty / error 状态规范，以及活动广场、活动详情报名、主办工作台三个高保真页面。
