## 三、注册商选择（考虑未来 ICP 备案）

| 注册商 | 优点 | 缺点 | 适合 |
|---|---|---|---|
| **阿里云万网** | 国内最大注册商；实名认证、备案、DNS 一站式；备案流程中文引导详细 | .com 续费 95 元略贵于海外 | ✅ 首选，尤其要备案 |
| **腾讯云 DNSPod** | 价格与阿里云接近或略低（.com 续费约 90）；未来做微信小程序生态更顺（同为腾讯系） | 与阿里云差异不大 | ✅ 同样推荐 |
| Cloudflare | .com 续费约 $10.44 成本价，全球最便宜之一 | **无法直接备案**（备案要求域名在工信部批准的境内注册商完成实名认证）；界面英文 | ❌ 不适合本项目 |
| Namecheap | 首年常有促销 | 同上，备案需先转入国内注册商（转移需 60 天等待期+麻烦） | ❌ 不适合本项目 |

**关键规则**：ICP 备案要求 ① 域名后缀在工信部批复列表内（domain.miit.gov.cn 可查）；② 域名在境内注册服务机构完成实名认证；③ 备案主体与域名持有人实名信息一致。在海外注册商买域名，备案前必须转入国内注册商，白白多一道工序。**直接在阿里云或腾讯云买，一步到位。**

## 四、备案与合规注意事项

1. **实名认证**：所有国内注册的域名（含 .com/.cc/.cn）都需实名。.cn 个人注册需上传身份证，CNNIC 审核约 3 个工作日。实名通过前域名处于 ServerHold 状态无法解析。
2. **可备案后缀确认**：.com / .net / .cn / .com.cn / .cc / .top / .xyz / .club / .site 均已获工信部批复（.cc 于 2020 年获批）。冷门新后缀购买前务必先在 domain.miit.gov.cn 查询。
3. **微信小程序**：业务域名/服务器域名必须是已 ICP 备案的域名且启用 HTTPS。这意味着上小程序前必须完成备案，而备案（网站备案）通常要求服务器在境内——纯 Vercel 部署无法完成网站备案。届时方案：主站备案接入国内云（如腾讯云轻量服务器），或小程序 API 单独部署国内。买域名时选国内注册商就是为这一步铺路。
4. **Vercel 现阶段**：域名解析到 Vercel（境外节点）不需要备案，买完即可用；备案是未来上小程序/国内加速时才需要。
5. **注册年限**：建议 .com 一次买 2–3 年锁定价格；实名信息填写个人真实姓名（未来备案主体若是个人，必须一致）。

### 新手购买步骤（以腾讯云为例，阿里云流程几乎相同）

1. 打开 `dnspod.cloud.tencent.com` 或 `wanwang.aliyun.com`，注册账号并完成**个人实名认证**（微信/支付宝扫脸，几分钟）。
2. 首页搜索框输入 `gojuhui`，在结果里勾选 `.com`，点"加入购物车"→"立即结算"。
3. 购买年限选 **2–3 年**（防止忘续费+锁价）；勾选"域名信息模板"，按提示新建模板填真实姓名+身份证（这就是域名实名，未来备案要用）。
4. 支付（微信/支付宝均可）。实名审核通常几小时–3 个工作日。
5. 审核通过后，进控制台 →「域名管理」→「DNS 解析」，按 Vercel 项目里 Settings → Domains 给出的记录添加：`A 记录 @ → 76.76.21.21`，`CNAME www → cname.vercel-dns.com`（以 Vercel 页面实际提示为准）。
6. 回到 Vercel 点 Verify，等待生效（几分钟到几小时），HTTPS 证书 Vercel 自动签发，完成。
