## 4) App description

### 4.1 Short description (ZH)

GatherUp 是面向线下活动组织者与参与者的协作工具，覆盖报名、票务、退款、通知与现场执行流程。

### 4.2 Short description (EN)

GatherUp is a collaborative tool for offline event organizers and attendees, covering registration, ticketing, refunds, notifications, and onsite workflows.

### 4.3 Full description (ZH)

GatherUp 帮助线下活动从“发布到落地”顺畅运转。组织者可以创建活动、管理报名、审核付款凭证、处理退款、安排座位与签到；参与者可以完成报名、上传凭证、接收通知并跟进订单状态。  
我们聚焦真实线下活动运营，不是简单内容展示应用。  

核心能力包括：  
- 活动创建与报名管理  
- 付款凭证上传与审核协作  
- 候补、选座与签到流程  
- 退款申请、处理与状态追踪  
- App 内通知与 Apple 推送提醒  
- Sign in with Apple 账号体系  

### 4.4 Full description (EN)

GatherUp helps offline events run smoothly from launch to onsite execution. Organizers can create events, manage registrations, review payment proofs, process refunds, and coordinate seating/check-ins. Attendees can register, upload payment proof, receive notifications, and track order status.  
GatherUp is built for real operational workflows, not just content display.

Key capabilities:
- Event creation and registration management
- Payment proof submission and review coordination
- Waitlist, seat selection, and check-in workflows
- Refund request handling and status tracking
- In-app notifications and Apple Push delivery
- Sign in with Apple account experience
